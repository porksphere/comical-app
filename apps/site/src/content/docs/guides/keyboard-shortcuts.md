---
title: Keyboard shortcuts
description: The desktop and web app's keyboard map, built for one hand on the left of the keyboard.
---

The desktop and web apps are driven from the left hand: **WASD** under the fingers, **Space** under
the thumb, modifiers under the pinky. The arrow keys work as aliases. **F1** shows this list in the
app; **Settings → Keyboard shortcuts** rebinds any of it, and has a **mirrored** preset that moves
the whole map to the right hand (IJKL, 6–0).

## Everywhere

| Key | Action |
|---|---|
| `W` `S` / `↑` `↓` | Up / down — scrolls, pans a zoomed page, or moves the focus |
| `A` `D` / `←` `→` | Left / right — turns the page, or moves the focus |
| `Alt+A` / `Alt+D` | Back / forward |
| `Esc` | Close — leaves a text field, then closes what's open, then lets go of the focus, then goes back |
| `Ctrl+K` (`⌘K`) | Search |
| `Ctrl+F` (`⌘F`) | Filter this screen |
| `F` | Add to library (in the reader: save the page) |
| `1` `2` `3` `4` `5` | Browse, Library, History, Activity, Settings — again to step through a tab's sources or collections |
| `F1` | Keyboard shortcuts |

## Lists and screens

| Key | Action |
|---|---|
| `Space` | Open what has the focus; with nothing focused, focuses the first thing on screen |
| `R` | Menu — what a right-click or long press opens |
| `Shift+W` / `Shift+S` | Scroll up / down, even while something has the focus |

## Reader

| Key | Action |
|---|---|
| `Space` | Next page (scrolls a screen first where there's more page) |
| `Shift+Space` | Previous page |
| `Shift+D` / `Shift+A` | Next / previous chapter (swapped for right-to-left) |
| `E` / `Q` | Zoom in / out — hold to keep zooming, press twice for all the way |
| `+` / `-` | Zoom in / out a step |
| `0` | Reset zoom |
| `X` | Switch fit — fit the other side of the page |
| `Tab` | Reader controls — shows the toolbar and focuses it |

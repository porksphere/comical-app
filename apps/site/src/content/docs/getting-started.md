title: Getting started
description: From a fresh install to reading — add a registry, install a bridge, save a series.
---

Comical ships empty on purpose. Everything you read comes through a **bridge**, and bridges come
from a **registry** you choose to add. Five minutes covers it.

## 1. Add a registry

Open **Settings → Bridges** and tap **Add registry**. Paste the registry's URL — the address of its
`index.json`, which the registry's own page will give you.

Registries published on GitHub tag themselves with the
[`comical-registry`](https://github.com/topics/comical-registry) topic, which is the easiest way
to find them. The topic is self-applied, so it's a directory, not an endorsement: read a
registry's description before you add it.

When you add a registry Comical fetches its index and, if the registry is signed, remembers its
key — from then on every bridge it serves is verified against that key before it runs.

## 2. Install a bridge

The registry's bridges are now listed under it. Each one names what it connects to, its language,
and whether it carries adult content. Tap **Install** on the ones you want.

Some bridges need to be told where to go — a server address, an account. Those show a **settings**
icon after install; fill in what they ask for.

On iOS and Android, bridges run **on the device**. Nothing is sent to anyone but the source the
bridge talks to. On the web they run in the backend you host.

## 3. Browse

Back on the **Browse** tab, each installed bridge is a source you can switch between from the
title at the top. A source opens on its featured lists; search covers every source at once from
the search button, or just the one you're looking at.

## 4. Save and read

Open a series and tap **+ Library** to keep it. Tap a chapter to read, or **Resume** to pick up where
you left off. The reader's controls hide after a moment; tap the page to bring them back.

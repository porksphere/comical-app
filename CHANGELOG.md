# Changelog

Every released version, newest first. New sections are generated by
`.github/scripts/prepare-release.sh`, which the **Prepare release** workflow runs when you dispatch
a version bump — see [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).

Binaries for each version are attached to its
[GitHub Release](https://github.com/porksphere/comical-app/releases).
